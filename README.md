# YouTube Downloader

Небольшое веб-приложение: вставляете ссылку на видео с YouTube — файл скачивается на компьютер.

Использует [yt-dlp](https://github.com/yt-dlp/yt-dlp) для получения видео. Для личного использования — скачивайте только то, на что у вас есть право (собственные видео, публичный домен, контент с разрешением автора).

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для скачивания в максимальном качестве (когда видео и звук отдаются отдельными потоками) дополнительно нужен `ffmpeg`:

```bash
brew install ffmpeg
```

Без `ffmpeg` приложение всё равно работает, но берёт лучший доступный вариант, где видео и звук уже объединены в один файл.

## Запуск

```bash
python3 app.py
```

Откройте [http://localhost:5001](http://localhost:5001), вставьте ссылку и нажмите «Скачать».

## Если YouTube просит "Sign in to confirm you're not a bot"

Иногда YouTube требует подтверждения, что вы не бот (особенно с серверных/облачных IP, но в 2025-2026 это стало происходить и с обычных домашних). Решение — экспортировать cookies из своего браузера (например, расширением "Get cookies.txt LOCALLY") и сохранить файл как `cookies.txt` в папке проекта. Приложение подхватит его автоматически. Файл в `.gitignore` — в репозиторий не попадёт.

## Если ошибка "downloaded file is empty" / HTTP 403 при скачивании

Это отдельная, более серьёзная защита YouTube (SABR streaming / PO Token) — она блокирует не доступ к странице, а сам файл видео, даже с валидными cookies. Cookies одни эту проблему не решают.

Рабочее решение — локальный генератор PO Token ([bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider)), который требует Node.js. Уже частично настроено в этом проекте:

- `.nodeenv/` — локальная копия Node.js (не влияет на систему), уже установлена
- `.bgutil-provider/` — исходники провайдера, уже склонированы

Осталось собрать сам провайдер (нужно ваше подтверждение, так как `npm install` может выполнять сторонний код при установке зависимостей — это заблокировала автоматическая проверка безопасности):

```bash
cd ~/Desktop/Claude/youtube-downloader
source .nodeenv/bin/activate
cd .bgutil-provider/server
npm install
npm run build
```

После этого просто перезапустите `python3 app.py` — `app.py` сам обнаружит собранный провайдер (`.bgutil-provider/server/build/generate_once.js`) и начнёт использовать его автоматически, никаких дополнительных настроек не нужно.
